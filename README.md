# Assignment 4: Heap Data Structures

This project implements Heapsort and a max-heap priority queue in Python. It compares Heapsort with Quicksort and Merge Sort and demonstrates task scheduling based on priority.

## Files

- `heapsort.py` – Heapsort implementation and testing.
- `comparison.py` – Sorting performance comparison.
- `priority_queue.py` – Max-heap priority queue operations.
- `scheduler.py` – Priority-based task scheduling simulation.
- `Assignment_4_Report.docx` – Assignment report with results and analysis.

## How to Run

Open the project folder in VS Code and run:

```bash
python heapsort.py
python comparison.py
python priority_queue.py
python scheduler.py
```

## Summary

The results show that Heapsort provides O(n log n) time complexity, while Quicksort and Merge Sort may perform faster depending on the input. The priority queue efficiently schedules higher-priority tasks, although lower-priority tasks may experience longer waiting times.
